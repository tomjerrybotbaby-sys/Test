Questions people ask

Is it free to pair?

Pairing itself is just a number and a temporary code. No password is shared.

My code does not work. What should I do?

Codes expire quickly. Enter your international number with country code and generate a fresh code.

Which countries are supported?

Any country is supported. Type your number with the country code, for example 8801XXXXXXXXX.

How do I disconnect the bot?

Open WhatsApp, go to Linked devices, select the session and choose Log out.

Should I use code or QR?

Use the pairing code when you are linking from the same phone. It is the simplest method here.
